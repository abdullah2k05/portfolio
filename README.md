# Abdullah's Portfolio

Static React + Vite site. **All site content lives in one file:** `src/data/defaultPortfolioContent.js`

## Updating or adding content

1. Edit `src/data/defaultPortfolioContent.js` — sections: `aboutParagraphs`, `aboutStats`, `aboutHighlights`, `skills`, `projects`, `products`, `photoSlides`, `events`, `experience`, `education`.
2. Check it locally: `npm run build && npm run preview`
3. Commit and push — Vercel deploys automatically.

There is no database, no API key, and no admin panel: content is baked into the build, so it can never drift, pause, or leak.
